# Voices

Put short reference recordings here (WAV, 16-bit, 5-15 seconds of one man speaking clearly):

- `GER/` - voices for German soldiers
- `SOV/` - voices for Soviet soldiers
- `ANY/` - used for either side when that side has none

Each file becomes a voice Chasm's TTS (Qwen3-TTS) clones; every soldier is given one voice of his
side and keeps it. Use recordings you have the right to use - your own voice, friends, or clips
under a free licence. The bridge copies them into Chasm's voices folder when it starts.
With no clips, soldiers speak in subtitles only.
